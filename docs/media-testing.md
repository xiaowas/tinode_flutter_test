# Android 附件与录音验证

本次接入使用 Android 系统文件选择器、相机、MediaRecorder/MediaPlayer，以及现有 Tinode SDK。不需要新增 Flutter 插件。原生代码与 Manifest 有变更，需要退出当前运行后重新构建：

```sh
flutter test
flutter run
```

## 双客户端验收

使用两个不同账号登录本项目和参考 Android 客户端。

| 场景 | 预期 |
| --- | --- |
| 输入文字，再清空 | 麦克风切换为发送按钮，再恢复麦克风 |
| 图片 → 相册 / 拍照 | 选择后预览；取消不发送；确认后对方可查看图片 |
| 视频 → 相册 / 录像 | 确认发送；双方可点击卡片通过系统播放器打开 |
| 回形针选择 PDF | 显示名称和大小，确认后发送，接收方可下载并打开 |
| 对方发送图片 / 文件 / 语音 | 本项目显示对应类型，历史加载后仍能打开或播放 |
| 拒绝麦克风权限 | 显示权限错误，不启动录音 |
| 按住麦克风超过一秒后松开 | 发送语音，对方可播放并显示时长 |
| 录音向左滑动 | 取消，不发送 |
| 录音向上滑动后松开 | 保持录音；停止后可试听、取消或发送 |
| 点击麦克风 | 开始锁定录音；停止后预览 |
| 授权麦克风前已经松手 | 授权回来后取消录音，不误发送 |
| 录音时切后台 | 停止并丢弃当前录音 |
| 上传失败 | 保留附件，可重新发送；成功后清除预览 |
| 超过服务器文件大小限制 | 显示错误，不尝试发送超大文件 |
| 切换语音播放 | 停止上一个音频，播放完成后恢复播放按钮 |

上传采用服务器返回的文件大小限制，未提供时为 8 MB。录音为 AAC/M4A，最长十分钟，短于一秒不发送。缓存保存在应用私有 cache/attachments 中，发送或取消后清除源文件，七天以上的缓存在下次初始化时清除。

图片在应用内预览，文件和视频下载到私有缓存后通过 FileProvider 交给系统应用打开。认证信息只附加给与 Tinode 服务器同源的下载地址；重定向下载会返回错误，不把认证信息传到其他地址。HTTP 放行仅针对当前配置的 Tinode 主机；更换主机时同步修改 network_security_config.xml。

## 自动测试与当前验证范围

`test/media_test.dart` 覆盖按钮切换、附件预览/取消/重试、录音停止试听、长按发送、滑动取消/锁定、延迟授权取消和播放结束事件。

这些是使用模拟 MethodChannel 的界面测试，不代表已验证真实相机、录音硬件或服务端上传。开发环境的自动审批服务返回模型配置 404，阻止了本次 flutter test 执行；需在本地运行上述命令并完成双客户端验收。
